# ADR 0036 — Xóa `modules/hr`; phần quyền vào `permission`, `/me` vào `authentication`

Ngày: 2026-10-23. **Trạng thái: Accepted** (người dùng chốt: không có nghiệp vụ hay bảng nào là "hr", tất cả quy về role và permission; "phần quyền vào permission, /me thì cho vào authentication"). Tiếp ADR 0035 (mục "Việc để lại"). Chỉ đổi đường dẫn và tên định danh TypeScript; không đổi giá trị chuỗi đã lưu, SQL, grant, migration (class, timestamp, nội dung), route `/api/hr/*`, OpenAPI, quyền hay hành vi.

## Quyết định

1. Folder `apps/api/src/modules/hr/` không còn. Module nghiệp vụ chỉ import nền tảng và `modules/permission`.
2. **Phần quyền** vào `modules/permission/`: SQL phạm vi, grant của data/authority/sync login, view phạm vi, hằng neo (`permission-database.helper.ts`) và object registry (`permission-object.repository.ts`). Tên class `PermissionObjectRepository` (không `ObjectRegistry...`): repository này ghi `object_ref` qua hàm SQL `hr_register_object` và tạo hai neo singleton của chính các resource `hrCompany`/`workCalendar` do `permission` sở hữu, nên tên theo module sở hữu như mọi repository khác; chỉ một file nên đặt trực tiếp trong module.
3. **Phần dùng chung không phải quyền** vào `src/infrastructure/helpers/` (cạnh `api-error.helper.ts`, `http-security.helper.ts`): các module nghiệp vụ đã import thư mục này (ESLint chỉ cấm `database/**`, `audit/**`, `authorization/services/**`… cho file HTTP, không cấm `infrastructure/helpers`), và nó không gắn với quyền: validate body/query (`input-validation.helper.ts`), replay idempotency (`idempotency.helper.ts`), đồng hồ nghiệp vụ trong SQL (`business-time.helper.ts`), nhận biết vi phạm UNIQUE (`database-error.helper.ts`). Mọi file vẫn là `*.helper.ts` đồng bộ (không `async`/`Promise`), nằm dưới luật `helper-sync`.
4. **`GET /api/hr/me`** (nay `GET /api/auth/me`, xem cập nhật cuối) thuộc `authentication`: `authentication/controllers/me.controller.ts` (`MeController`, `@Controller('api/hr')` giữ path; classification `ProductAuthenticated`, response, status và Swagger giữ nguyên, OpenAPI là schema tĩnh trong `openapi/`). Operation `me(secret)` thêm vào `AuthenticationHttpPort`; cài đặt ở `infrastructure/runtime.module.ts` ghép `runtime.currentSession` và `employees.me` như trước, nên `authentication` chỉ biết port/token, không import code module nghiệp vụ (ADR 0031). Kiểu `MeView`/`MeMenu` (cũ `HrMeView`/`HrMenu` trong `employee.types.ts`) chuyển vào `authentication.http-port.ts`; `employee` import kiểu từ nền tảng.
5. **Composition**: `infrastructure/product-hr.factory.ts` thành `product-modules.factory.ts`; test `hr-template.helper.ts` thành `module-template.helper.ts`.

## Giữ nguyên

Tên sản phẩm `hrm` (test `hrm-*`, env `HRM_*`, `hrm-*.migration.ts`, class migration), role `hr.*`, policy `hrRead`…, resource `hrCompany`, boundary `hrAdministration`, bảng/view/hàm `hr_*`, route `/api/hr/*`, `startHrStack`, tên database template test `hr_<digest>`, và export `hrScopeViews`/`hrOwnerViews`/`hrRequestViews`/`hrRegisterObjectBodyT3` trong file migration (đổi chạm migration đã áp dụng). Các thứ này cần release hoặc ADR riêng nếu muốn bỏ.

## Hệ quả

`permission-database.helper.ts` vẫn import migration của `employee` và `work-request` (nợ import chéo đã ghi ở ADR 0031, chỉ đổi nơi chứa). Hash OpenAPI, route inventory, release 16, bindings và canonical không đổi (xem báo cáo kiểm thử của thay đổi này).

Cập nhật (ADR 0037, 2026-10-23): mục 4 được thay: `/me` thành `GET /api/auth/me` (`userId` + `menus`) và hồ sơ nhân viên sang `GET /api/hr/employees/me`; `GET /api/hr/me` không còn.

## Bổ sung (2026-10-23): dọn nốt định danh `hr` trong `apps/api`

Người dùng chốt "dọn hết" chữ `hr` còn lại: mục "Việc để lại" của ADR 0035 và các tên ở mục "Giữ nguyên" bên trên (trừ giá trị lưu) đã đổi. Chỉ đổi tên định danh TypeScript, tên file, tên database template test, thông điệp lỗi nội bộ và comment; không đổi SQL, tên bảng/view/hàm, class và timestamp migration, giá trị lưu, route, OpenAPI hay hành vi.

Chuỗi `hr` còn lại là chủ đích, vì là giá trị lưu hoặc hợp đồng đã công bố: role key `hr.*`; policy `hrRead`/`hrSubmit`/`hrWrite`/`hrFresh`; resource `hrCompany` (và action `hrCompany.*`); boundary `hrAdministration`; tên domain relation lưu trong declarations (`hrEmployeeLead`, `hrEmployeeOwner`, `hrLeaveRateOwner`, `hrTeamMember`, `hrTeamLead`, `hrRequestOwner`/`Lead`/`Decider`/`LeadRejected`, đồng thời là tên view); bảng/view/hàm/constraint SQL `hr_*` (`hr_company`, `hr_register_object`, `hr_idempotency`, `hr_employee_owner`...); kind audit `hr.*`; route `/api/hr/*`; tên sản phẩm `hrm` (file `hrm-*`, env `HRM_*`, class migration `Hrm*`). Chữ "HR" trong comment mô tả vai trò (role HR) và nhãn tiếng Việt cũng giữ vì role đó còn tồn tại. Bỏ các giá trị này cần release/migration và ADR riêng. Web (`apps/web/src/features/hr`, `useHrMe`...) chưa đổi, làm cùng đợt đổi tên web.
