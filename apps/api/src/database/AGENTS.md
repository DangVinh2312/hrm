# Database

Đọc root và `apps/api/AGENTS.md`. Module này giữ fixed-purpose transactions, DB configuration/probes và product migrations; không phải package adapter hoặc generic repository framework.

- `product-transaction.runner.ts`: READ COMMITTED, fence trước facts, retry/deadline hữu hạn, shared cho read/write/identity; exclusive cho facts mutation/sync. Không nâng shared thành exclusive.
- `helpers/transaction-errors.helper.ts`: class lỗi và runtime capability của product runner; giữ một class identity để filter/retry nhận đúng lỗi.
- `helpers/product-database.helper.ts`: phần đồng bộ (purposes, function owners, `productMigrations` = baseline sản phẩm, `allMigrations` = baseline sản phẩm + baseline ứng dụng — danh sách duy nhất cho CLI và test, `productDataSourceOptions`, `grantsOf`). `product-privilege.declarations.ts`: credential matrix, ACL/view/trigger/function kỳ vọng. `services/product-database-provision.service.ts`: provisioning offline. `services/product-privilege-verify.service.ts`: exact privilege/protection probes. HTTP runtime chỉ dùng verify; provisioning/options/migration registry chỉ apps/api/tools/tests dùng. Helper không dùng async/await/Promise (ADR 0033, 2026-10-23; ESLint `no-restricted-syntax` trong `apps/api/eslint.config.js`, kiểm bởi `apps/api/test/helper-sync.spec.ts`).
- `migrations/` (ADR 0048, 2026-10-29): đúng **hai baseline**, thay mọi migration 001–021, `ProductDocument` và HR 100–114 trước đó (các số này chỉ còn trong ADR/plan cũ làm lịch sử). `001-product-baseline.migration.ts` (`ProductBaseline1792108800001`): schema identity/authority ở dạng cuối, hàm/trigger/ACL/owner; export các body chính xác mà `product-privilege.declarations.ts` và test dùng (`sharedFenceBody`, `resolveSessionOidcBody`, `guardRoot*Body`, `reactivateIamAccountBody`, …). `002-application-baseline.migration.ts` (`ApplicationBaseline1792108800002`): fixture `document` (`documentFixtureSql`) và schema HR; export `registerObjectBody`, `authorizationScopeViews`, `employeeOwnerViews`, `requestLeadViews` cho probe HR. Cả hai chạy trên database rỗng và qua `db:provision` (đổi owner sang role NOLOGIN cần membership tạm); `db:migrate` đơn lẻ không áp dụng được baseline. Baseline không có nhánh chuyển dữ liệu cũ: database dựng bằng chuỗi 001–021 cũ bị bỏ và dựng lại.
- **Luật migration áp dụng lại từ baseline:** class name/timestamp/SQL của migration đã áp dụng (hai baseline và mọi migration sau chúng) không được đổi. Thay semantics chỉ bằng forward migration mới (timestamp lớn hơn, đặt cạnh baseline hoặc ở feature, đăng ký trong `allMigrations`); không chạy DDL trong boot, `synchronize: false`. Sửa baseline chỉ hợp lệ khi chưa có database nào ngoài máy dev áp dụng nó, và phải ghi ADR.
- Hàm `reactivate_iam_account` (ADR 0043): owner `product_account_owner`, EXECUTE chỉ `authority`; `protect_account_lifecycle` xét `current_user` nên không đổi. Mở rộng ACL owner phải đổi `accountOwnerAcl` và probe cùng lúc.
- Bảng `setting_anchor`, `system_setting`, `system_setting_history` (ADR 0045): `product_data` không có DELETE trên setting và chỉ SELECT/INSERT trên history, trigger `forbid_setting_history_change` chặn UPDATE/DELETE/TRUNCATE; grant ở `permissionPrivileges` (`permission-database.helper.ts`), probe `verifySettingSchema` đòi trigger bật.
- Bảng `role_anchor` (ADR 0046): bản ghi neo của `role.*`; `product_data` chỉ SELECT, `product_sync` SELECT/INSERT, grant ở `permissionPrivileges`. Không đổi `role_definition`/`policy_rule`; CHECK cho role runtime (ADR 0047) là forward migration mới cùng write path.
- Một database, credentials data/identity/authority/sync/migration/bootstrap riêng. API không giữ migration/bootstrap credentials; không fallback pool khi thiếu capability.
- Chỉ dùng transaction manager truyền vào; identifiers từ registered binding, giá trị parameterized. Không dump SQL binds, URLs hoặc raw DB errors.
- Privilege/protection tests dùng credential thật và PostgreSQL disposable: kiểm owner/ACL, SECURITY DEFINER/search_path/body, trigger enabled/binding, CREATE/TEMP/grant option; không hardcode tổng trigger thay kiểm từng bảo vệ.
- Migration ứng dụng mới đặt ở feature tương ứng và đăng ký vào `allMigrations` (một nơi, `helpers/product-database.helper.ts`); không tự thay protected functions/triggers để làm probe pass.
- ADR 0014 đã bỏ tenant/identity schema cũ; hai baseline ở đây là đường dựng schema hiện tại.

Tests: `apps/api/test/product-database.integration-spec.ts`, `apps/api/test/product-genesis.integration-spec.ts`, `apps/api/test/product-root-guards.integration-spec.ts`, cùng các suite locks/fence/privileges thực tế. Cần Docker; không SQLite hoặc database thật của người dùng.
